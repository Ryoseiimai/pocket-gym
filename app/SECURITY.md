# セキュリティポリシー

## 対応バージョン

本リポジトリは単一バージョンで運用しています。常に `main` ブランチの最新版がサポート対象です。

## 脆弱性の報告先

脆弱性を見つけた場合は、公開のIssueではなく **GitHub Security Advisories** から報告してください。

1. リポジトリの「Security」タブを開く
2. 「Report a vulnerability」から非公開で報告する

個人情報やログイン機構は扱っていませんが、XSS等のクライアントサイドの脆弱性は深刻に受け止めます。
報告いただいた場合はできる限り速やかに対応します。

## このアプリのセキュリティ上の設計

- バックエンドなし・ログインなし。全データはブラウザの localStorage のみに保存されます。
- 依存ライブラリ・外部CDN・外部スクリプトを一切使用しません。
- 厳格な Content-Security-Policy を設定しています（`index.html` 参照）。
- `innerHTML` / `eval` / `new Function` / `document.write` を一切使用していません。
- JSONインポート時は型・必須キー・件数上限・文字数上限を検証し、不正なデータは保存しません。
